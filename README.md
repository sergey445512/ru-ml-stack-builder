# Конструктор Data / ML-стека

Небольшой самостоятельный учебный проект. Не требует Docker, сервера, регистрации или установки пакетов: скачайте репозиторий и откройте `index.html` в браузере. Интернет нужен только для перехода по ссылкам на источники и для загрузки необязательного веб-шрифта; сама логика работает офлайн.

Конструктор предлагает направление бизнеса, компанию из примеров, масштаб, тип инфраструктуры и задачи (ML, поток событий, аналитика, векторный поиск). На выходе — 20 технологических слоёв с объяснением, почему инструмент может быть нужен или почему его пока можно отложить. Результат копируется текстом.

## Главное ограничение

Название компании задаёт **учебный сценарий**, а не точную карту её инфраструктуры. Отрасль и размер не позволяют надёжно угадать конкретную СУБД, систему CI/CD или реестр образов. Поэтому в интерфейсе есть три состояния:

- **Подтверждено публикацией** — выбранный продукт прямо упомянут в материале самой команды. Публикация может описывать конкретный контур или исторический период; это не доказательство использования во всех продуктах компании сегодня.
- **Гипотеза** — возможное решение для выбранных параметров. Продукт не приписывается реальной компании.
- **Пока не требуется** — условия сценария пока не обосновывают отдельный слой.

Для большинства названий из списка нет проверенного в этой версии первичного источника. Конструктор честно показывает отраслевой аналог отдельно от прямых подтверждений. Он не вычисляет выдуманные вероятности использования технологий.

## Как показать на занятии

1. Выбрать СДЭК и показать слои с прямыми источниками.
2. Выключить «Есть аналитическое хранилище»: DWH, Spark и BI станут необязательными. Объяснить, что размер компании сам по себе не требует Spark.
3. Выбрать «Золотое яблоко»: название компании появится в сценарии, но ни один продукт не будет ложно отмечен как подтверждённый; ниже будет только отраслевой аналог Ozon Tech.
4. Включить «Нужен поиск по эмбеддингам» и показать, почему векторный слой возникает по задаче, а не по отрасли.

## Структура

- `index.html` — страница конструктора.
- `styles.css` — оформление и адаптация под телефон.
- `app.js` — справочник источников, отраслевые сценарии и правила выбора.
- `tests.html` — быстрая проверка всех комбинаций направлений и компаний в браузере.

Никакой связи с ML-платформой, её CI/CD или Docker volumes нет.
