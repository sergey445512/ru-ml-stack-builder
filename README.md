# Конструктор стека для ML-инженера

Лёгкий учебный сайт: скачайте и откройте `index.html` в браузере. Это автономный файл: весь код, данные и оформление уже внутри. Сервер, установка пакетов и остальные файлы репозитория для запуска не нужны.

[Открыть онлайн](https://sergey445512.github.io/ru-ml-stack-builder/)

Выберите направление и компанию. В 20 карточках показан путь от источников и подготовки данных до обучения, batch-скоринга, онлайн-инференса и мониторинга. ML предполагается во всех сценариях.

Одна карточка может содержать несколько инструментов с разными ролями. У **каждого** — собственный статус и источник. Нажмите инструмент, чтобы прочитать пояснение:

- **Кейс** — назван в публикации компании или исполнителя, для конкретного проекта и даты.
- **Упоминание / Trial** — вакансия, свидетельство сотрудника, историческое упоминание либо ограниченный статус в техрадаре. Подробности различаются в окне инструмента.
- **Предположение** — учебный выбор, не подтверждённый стек компании.
- **По задаче** — добавлять только при необходимости: например, Spark при больших расчётах или векторный поиск для эмбеддингов.

Наличие технологии в backend компании не доказывает её применение в ML. Полного текущего стека компаний мы не знаем. Для отсутствующих частей используется минимальный учебный сценарий. Отраслевые аналоги больше не окрашиваются как подтверждение для выбранной компании.

Кнопка **Источники** показывает материалы выбранной компании. **Скопировать** экспортирует инструменты вместе со статусами, пояснениями и ссылками.

Повторная проверка всех 23 компаний и ограничения доказательств: [RESEARCH.md](RESEARCH.md). Проверено 13 октября 2026 года.

## Файлы

- `index.html` — готовая автономная страница.
- `page.template.html`, `styles.css` — исходники интерфейса.
- `build.ps1` — обновление автономной страницы из исходников.
- `app.js` — направления и исходные публикации.
- `catalog.js` — профили компаний, дополнительные источники, сведения по каждому инструменту.
- `engine.js` — минимальные учебные дополнения, расчёт, интерфейс и экспорт.
- `tests.html` — проверки 23 компаний, статусов, переключения, диалогов и размеров экрана.
- `RESEARCH.md` — результаты веб-проверки.

Сеть нужна только для открытия ссылок на источники. Внешних шрифтов, аналитических счётчиков и серверной части нет.

После изменения исходников разработчик запускает `powershell -NoProfile -ExecutionPolicy Bypass -File ./build.ps1` (или `pwsh -File ./build.ps1`). Проверка соответствия страницы исходникам: тот же вызов с `-Check`. Пользователю для открытия страницы эта команда не нужна.

## Проверка

Откройте `tests.html` в браузере. Некоторые браузеры ограничивают доступ к iframe между локальными файлами; в таком случае используйте простой статический HTTP-сервер. Проверки должны закончиться строкой PASS.
