# Конструктор Data / ML-стека

Небольшой учебный сайт без сервера и зависимостей. Скачайте репозиторий и откройте `index.html` в браузере. Доступная онлайн-версия: https://sergey445512.github.io/ru-ml-stack-builder/.

Выберите направление бизнеса и одну из 23 компаний. Сайт соберёт примерный стек из 20 технологических слоёв. Во всех сценариях предполагается, что компания уже обучает и применяет ML-модели. Интерфейс помещается на одном экране на компьютере; источники открываются отдельным окном. Параметры нагрузки и инфраструктуры на странице не настраиваются: для каждого направления заложен учебный сценарий в `app.js`.

Сверка всех 23 компаний с публикациями и исходной таблицей находится в [`RESEARCH.md`](RESEARCH.md).

**Выбранная компания не означает, что весь показанный стек принадлежит ей.** У каждой технологии один из четырёх статусов:

- **Опубликовано** — технология названа в конкретной статье команды выбранной компании или описании её проекта. Ссылка на кейс находится рядом. Публикация может относиться к отдельному продукту или историческому периоду.
- **Отраслевой кейс** — технология названа у другой компании из того же или близкого направления. Это не подтверждение для выбранной компании.
- **Архитектурная гипотеза** — разумный вариант для учебного сценария; подтверждения именно этого выбора в приведённых кейсах нет.
- **Пока не требуется** — отдельный слой не нужен в выбранном сценарии.

Стек сочетает отдельные опубликованные сведения и учебные гипотезы. Его нельзя воспринимать как полную существующую архитектуру компании. Например, [Самолёт описывает MLflow, Airflow, Spark, Kafka, ClickHouse, Qdrant и Kubernetes](https://habr.com/ru/companies/samolet/articles/912782/), а [Туту описывает MongoDB, Kafka и ClickHouse](https://habr.com/ru/companies/tuturu/articles/883462/) в одном контуре. Остальные части их сценариев могут быть гипотезами.

## Файлы

- `index.html` — интерфейс.
- `styles.css` — оформление.
- `app.js` — направления, источники и учебные сценарии.
- `tests.html` — проверка сценариев в браузере.
- `RESEARCH.md` — результаты проверки компаний и ограничения источников.

Проект не связан с ML-платформой и её CI/CD. Он не отправляет запросы компаниям; сеть нужна только для перехода по ссылкам на источники.
