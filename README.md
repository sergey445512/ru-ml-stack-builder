# Конструктор Data / ML-стека

Небольшой учебный сайт без сервера и зависимостей. Скачайте репозиторий и откройте `index.html` в браузере. Доступная онлайн-версия: https://sergey445512.github.io/ru-ml-stack-builder/.

Выберите одно из восьми направлений бизнеса. Сайт покажет 23 названия компаний как примеры направлений и соберёт примерный стек из 20 технологических слоёв. Во всех сценариях предполагается, что компания уже обучает и применяет ML-модели. Параметры нагрузки, инфраструктуры и отдельных задач на странице не настраиваются; для каждого направления заложен один учебный сценарий в `app.js`.

Сверка всех 23 компаний с публикациями и исходной таблицей находится в [`RESEARCH.md`](RESEARCH.md).

**Названия компаний не означают, что показанный стек принадлежит им.** У каждой технологии один из трёх статусов:

- **Есть в публичном кейсе** — технология названа в конкретной статье инженерной команды или описании проекта. Ссылка на кейс находится рядом. Публикация может относиться к отдельному продукту или историческому периоду.
- **Архитектурная гипотеза** — разумный вариант для учебного сценария; подтверждения именно этого выбора в приведённых кейсах нет.
- **Пока не требуется** — отдельный слой не нужен в выбранном сценарии.

Один стек сочетает сведения из разных публикаций. Его нельзя воспринимать как существующую архитектуру какой-либо одной компании. Например, публикация Самолёта прямо описывает [MLflow, Airflow, Spark, Kafka, ClickHouse, Qdrant и Kubernetes](https://habr.com/ru/companies/samolet/articles/912782/), а [Туту описывает Kafka и ClickHouse](https://habr.com/ru/companies/tuturu/articles/883462/) для доставки аналитических данных. Эти свидетельства видны в карточках соответствующих направлений; остальные части сценария могут быть гипотезами.

## Файлы

- `index.html` — интерфейс.
- `styles.css` — оформление.
- `app.js` — направления, источники и учебные сценарии.
- `tests.html` — проверка сценариев в браузере.
- `RESEARCH.md` — результаты проверки компаний и ограничения источников.

Проект не связан с ML-платформой и её CI/CD. Он не отправляет запросы компаниям; сеть нужна только для перехода по ссылкам на источники и для необязательного веб-шрифта.
